# Demo Media Notes

The screenshots bundled with this repository are **generated portfolio illustrations**.

Why they are included:

- the original demo media was lost,
- the project still benefits from showing what the firmware output and monitoring views are intended to look like,
- and the generated images help make the repository self-contained for GitHub/portfolio use.

Included images:

1. `01_testbench_demo.png` — representative hardware bench scene
2. `02_uart_telemetry.png` — UART / serial-monitor output
3. `03_dashboard_normal.png` — monitoring dashboard in a healthy state
4. `04_dashboard_fault.png` — monitoring dashboard in a fault state

These visuals should be treated as presentation assets rather than original lab captures.
